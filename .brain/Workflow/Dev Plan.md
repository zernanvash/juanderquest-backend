## Key Principles
- Parallel tracks — mobile dev doesn't wait for backend
- Alpha = prototype scope (auth, browse, scan, submit, verify)
- Smart contracts developed alongside API (not sequential)
- Full feature set by beta test
- Mainnet deployment only after beta validation
